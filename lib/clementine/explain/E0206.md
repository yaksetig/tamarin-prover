# E0206: no executable lemma in verify block

## Summary

The `verify` block does not contain an `executable` query.
Clementine refuses to compile a protocol without one.

## Why this matters

The `executable` lemma asserts that *some* honest trace through the
protocol completes successfully. It is the only check that catches
the "all my secrecy lemmas pass because the protocol is unrunnable"
failure mode. Without it, a protocol with a typo that prevents any
rule from firing would silently verify every other lemma vacuously
— the secret is "secret" because nobody ever computes it.

This is invariant 6 of the nine compiler invariants in Clementine
design step 3 §3.4. It is enforced unconditionally; there is no
override flag.

## Example

```clem
verify {
  secrecy(k)
  injective_agreement(A, B, [k])
  // missing: executable
}
```

## Fix

Add `executable` to the `verify` block. The compiler will generate
a corresponding `exists-trace` lemma asserting that at least one
full honest run exists, with no LTK reveals.

```clem
verify {
  executable          // <-- add this
  secrecy(k)
  injective_agreement(A, B, [k])
}
```
